# BubblePop SwiftUI Score Game

A SwiftUI arcade game where players pop bubbles against a timer and build a score.

## Features

- Timed gameplay with score and combo feedback
- Configurable game settings
- High-score tracking stored locally with `UserDefaults`
- SwiftUI views and view models

Open `BubblePop.xcodeproj` in Xcode. The repository excludes local Xcode user state and build output.
